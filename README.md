# ACM-W_Contact-us
This repository contains the code for the contact-us part of the ACM-W website. this webpage leads to the Instagram, LinkedIn and Facebook handles of the club and also display the club logo.
---
## ⚠️ Important Notes
* **File Renaming for Pull Requests:**
  when submitting a pullrequest into the homeage repo , don't forget to rename the files as contact.js, contact.html etc
* **Navigation Link Behavior:**
  the nav links for About/Domains/Events/Fests/Projects all point to index.html#about, index.html#events, etc. — but in this repo, index.html is the contact page, not the homepage, so those will just scroll nowhere on this standalone site. Once you PR this into the homepage repo, you'll have to change those to point at wherever the actual homepage sections live.
